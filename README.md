# one-wallpaper

在 Windows 上打开一个窗口，框选网格，给每块区域接上自己的内容，然后设为桌面壁纸。每天到点可以由计划任务再跑一遍，不用开着窗口。

左边可以是一张图，右边可以是文字、列表、字段或进度条。仓库里的立绘、日期、天气、资讯、一句话、星座只是一份可载入的示例。

`lively/` 里仍留着一份 Lively Wallpaper 页面，本应用不再烘焙它。

## 开发

```bash
npm install
npm run dev
```

窗口是配置台。**设为壁纸**会抓接口、把壁纸页截成 PNG，并调用 `set_wallpaper.ps1` 铺到桌面。

配置和生成的图不在仓库里，而在 `%APPDATA%\one-wallpaper\`：`config.json` 与 `output\today.png`。第一次启动若那里还没有配置，会用仓库里的 `config.json` 做种子。

## 安装包

```bash
npm run dist
```

安装包在 `release/`。计划任务指向安装后的程序，参数是不出窗口的生成。

## 每日更新

在配置台打开「计划任务」，点 **安装 / 更新**。到点启动本程序，不打开窗口，按已保存的配置设壁纸。**现在跑一次**会立刻重做一遍。

## 画面

分辨率、列行、间距、边距、任务栏高度都在配置台里改。内容画在任务栏之上。一块区域可以是空白、纯文字、纯图片，或接一个接口。接接口时用网址和查询参数，值里可以写 `{date}`（当天 `YYYYMMDD`）。测试后从完整返回里点选路径，同一份返回可以挂多条展示：文字、列表、图片、进度条、字段组。

## 目录

```
one-wallpaper/
├── config.json          第一次启动时的种子配置
├── src/                 Vue 配置台，以及用来截图的壁纸页
├── electron/            主进程：抓取、截图、设壁纸、计划任务
├── shared/              网格、校验、展示数据
├── set_wallpaper.ps1    把 PNG 设为桌面壁纸
└── lively/              独立的 Lively 页面，本应用不改、不烘焙
```
